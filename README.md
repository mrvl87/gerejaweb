# GKI Di Tanah Papua

Website gereja berbasis Astro + Keystatic dengan deploy target Vercel.

## Stack

- Astro
- Keystatic
- Vercel

## Menjalankan Lokal

```bash
npm install
npm run dev
```

CMS tersedia di `/keystatic`.

## Build

```bash
npm run check
npm run build
```

## GitHub Mode Keystatic

Untuk mengaktifkan mode GitHub pada Keystatic, set environment variable berikut:

```bash
KEYSTATIC_GITHUB_REPO=owner/repo
```
